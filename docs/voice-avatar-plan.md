# แผนงานถัดไป: ตัวละครมีชีวิตในโหมดสนทนาด้วยเสียง

สถานะ: **ยังไม่เริ่ม** — รอผู้ใช้เตรียม asset ตัวละครก่อน

## เป้าหมาย

แทนที่ (หรือเสริม) โครงข่ายเซลล์ประสาทบน `<canvas>` ในโหมดเสียง ด้วย**ตัวละครที่ดูมีชีวิต**
— ขยับปากตามเสียงพูดจริง, กระพริบตา/หายใจตอนว่าง, ท่าทางเปลี่ยนตาม state (ฟัง/คิด/พูด)
ให้ความรู้สึกเหมือนคุยกับตัวละคร (เช่น Asuna ที่โคลนเสียงไว้) ไม่ใช่แค่กราฟิกนามธรรม

## สิ่งที่มีอยู่แล้ว (ใช้ต่อได้ทันที ไม่ต้องแก้)

`static/js/voice.js` มี state machine + สัญญาณเสียงพร้อมใช้อยู่แล้ว:
- `state` — `listening` / `thinking` / `speaking` / `error` / `off`
- `level` (0–1) — ระดับเสียงจริงแบบ real-time: จากไมค์ (`AnalyserNode`) ตอนฟัง, จากเสียง
  Cartesia ที่กำลังเล่น (`ttsAnalyser`) ตอนพูด
- ลูป `render(now)` ที่รันทุกเฟรมอยู่แล้ว (ตอนนี้ใช้วาดโครงข่ายเซลล์ประสาท) — เปลี่ยนแค่สิ่งที่
  วาดในนี้ให้เป็นตัวละครแทน ส่วน state/level/audio pipeline ไม่ต้องแตะ

พูดง่ายๆ คือ **งานนี้คืองาน "เปลี่ยนสิ่งที่วาดบน canvas"** ไม่ใช่งานสร้างระบบเสียงใหม่

## ข้อจำกัดของผม (Claude)

สร้างไฟล์โมเดล 3D/2D ที่ริกแล้ว (mesh, กระดูก, blend shape ขยับปาก) ให้ไม่ได้ — ไม่มี
ความสามารถแปลงภาพ/สร้างโมเดลในตัว **แต่เขียนโค้ดเอาโมเดลมาโหลด + ขยับ + เชื่อมกับสัญญาณ
เสียงที่มีอยู่แล้วได้เต็มที่** — ผู้ใช้ต้องเตรียมไฟล์โมเดลมาก่อน ผมถึงต่อเข้าระบบให้

## ทางเลือกเครื่องมือสร้าง asset (ผู้ใช้ทำเอง)

| ทาง | เครื่องมือ | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **VRM (3D อนิเมะ)** — แนะนำ | [VRoid Studio](https://vroid.com/studio) (ฟรี) | ปรับสไลเดอร์ให้ใกล้เคียงต้นแบบเอง ได้ blend shape ปาก/ตาสำเร็จรูปพร้อมใช้ ไม่ต้องริกเอง | ไม่ใช่ auto จากภาพ ต้องปรับเอง |
| **Image-to-3D อัตโนมัติ** | Tripo AI (tripo3d.ai) / Meshy AI (meshy.ai) / Rodin (Hyper3D) | ใส่ภาพ ได้ mesh+texture เลย มี free tier | ยังไม่มีโครงกระดูก/ขยับปากไม่ได้ ต้องไปริกต่อ (Blender + Mixamo) |
| **Live2D (2D ริก)** | Live2D Cubism (ฟรีสำหรับใช้ส่วนตัว) | ดูมีชีวิตง่ายกว่า/เร็วกว่าทำ 3D เต็มรูป เหมาะกับ "หน้าพูด" โดยเฉพาะ | ต้องมีภาพประกอบแบบแยกเลเยอร์ก่อน |

## แผนการต่อเข้าระบบ (ทำตอนมี asset แล้ว)

1. **VRM path** — โหลดไลบรารี `three` + `@pixiv/three-vrm` (CDN, ดูข้อจำกัด CDN ของโปรเจกต์)
   แสดงโมเดลแทน canvas เดิม, ขับ blend shape ปาก (`aa`/`ih`/`ou`...) ด้วย `level`, กระพริบตา
   สุ่มเป็นจังหวะตอน `idle`, เอียงหัวเบาๆ ตาม `state`
2. **Live2D path** — โหลด Live2D Cubism Web SDK, map พารามิเตอร์ปาก/ตาของโมเดลกับ `level`
   เหมือนกัน
3. ทั้งสองทาง: เก็บ `render()`/`resizeCanvas()` เดิมไว้เป็น fallback ถ้าโหลดโมเดลไม่สำเร็จ
   (เช่น ไฟล์เสีย/ยังไม่ได้ตั้งค่า) — โหมดเสียงต้องใช้งานได้ต่อแม้ไม่มีโมเดล
4. เพิ่มตัวเลือกใน Settings ถ้าต้องการสลับกลับไปโครงข่ายเซลล์ประสาทได้ (ออปชัน ไม่บังคับ)
